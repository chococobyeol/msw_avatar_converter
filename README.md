# MSW Avatar Converter

MapleStory/MeAegi avatar source importer and MapleStory Worlds avatar PSD conversion MVP workspace.

Current focus:
- Import public MeAegi share payloads.
- Show selectable source parts and full action-frame previews.
- Map every source part to a MapleStory Worlds avatar template part.
- Preserve MSW PSD templates under `avatartemplate/` for converter work.

Important limitation: current UI preview/import is ahead of final PSD pixel-writing parity. See `docs/source-and-api-boundaries.md` and `.omx/plans/` for implementation boundaries and remaining work.
